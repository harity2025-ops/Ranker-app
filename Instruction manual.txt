Software Requirements and User Guide

1. System Requirements

Operating System: Windows 10 or above
Java: Java 21 or above

Since this is lightweight software, RAM and storage capacity are not major concerns.

Make sure Java 21 or above is installed and properly configured in your system's environment variables.

2. About the Software

This software is designed to handle a flexible number of students and subjects. Each subject can have a different maximum mark (base mark), and any base mark can be used.

The marks are converted to a scale of 100 before ranking. Students are ranked using the competition ranking system, in which students with the same marks receive the same rank, and the subsequent rank is skipped accordingly.

The software can be used to convert marks for multiple subjects or for a single subject.

3. How to Use the Software and Manage Data

Use any spreadsheet software to enter the data. Microsoft Excel is recommended, but other spreadsheet software, such as LibreOffice Calc, can also be used.

Make sure to follow the provided spreadsheet format when entering the data.

Step 1: Create a Class Folder

Create a separate folder for each class. Inside the folder, create a spreadsheet file containing the students' names, subjects, the number of students, and the number of subjects.

Step 2: Enter Examination Marks

For each examination, enter the marks obtained by every student in the spreadsheet and save the file in the corresponding class folder using the examination name.

If a student is absent, enter 0 as their mark

You can also use the software to convert marks for an individual subject before entering them into the mark sheet. Just make sure to use the standard format that I 
have given.

Step 3: Import and Process the Data

Open the software and import the spreadsheet file.

If no errors are detected, the software will process the data successfully and generate the output spreadsheet in the specified format.

Step 4: Repeat for Other Classes

Repeat the process for each class. This allows you to maintain digital records of students' marks without having to maintain physical mark lists.
